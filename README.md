# SolidStart

Example [SolidStart](https://start.solidjs.com/) app. SolidStart is the full-stack framework for Solid, with routing and server-side rendering.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Static site — Railpack build |
| Single-page application (SPA) | off |
| Project directory | `/` |
| Output directory | `/.output/public` |
| Install command | leave empty |
| Build command | leave empty |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production with minification
npm run build

# preview the build locally
npm run preview
```

Requires Node.js 24 or later.
